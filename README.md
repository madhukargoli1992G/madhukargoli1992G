## ⚡ About

I build production-grade AI systems focused on **Retrieval-Augmented Generation, Agentic AI, and enterprise document intelligence**—especially where retrieval quality, grounding, hallucination control, latency, and scalable backend architecture must work together.

My work spans financial and regulatory document intelligence, hierarchical chunking, metadata-aware retrieval, vector and hybrid search, reranking, agentic workflows, verification loops, citation enforcement, FastAPI services, and cloud-native AI deployment. I enjoy owning the complete path from raw enterprise data to reliable, grounded intelligence.
